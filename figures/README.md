# Figures

Generated by `scripts/make_figures.py` (run in the `400` conda env):

```bash
conda run -n 400 python scripts/make_figures.py
```

Every figure is written as both **PDF** (vector, for the LaTeX paper) and **PNG**
(preview). The script reads only the CSVs under `results/` plus the curated
literature values in `scripts/literature_data.py`, so it is fast and does *not*
re-run the slow Cornell fit. Regenerate `results/` first if it is stale
(`conda run -n 400 python scripts/run_spectrum.py`).

## A — GEM basis / wavefunctions (the "expansion" plots)
| File | What it shows |
|------|----------------|
| `A1_gem_coverage_bb_1S` | Single paper-ready coverage plot: the 25 weighted Gaussian basis functions (dashed) summing to the total `u(r)=rR(r)` for the bottomonium 1S ground state. Replaces the commented-out `fig:gem_1S_coverage` in the paper. |
| `A1_gem_coverage_cc_1S` | Same, charmonium 1S. |
| `A2_gem_coverage_grid` | 2×3 grid: bb and cc {1S,2S,3S}. The 3S panels make the basis near-linear-dependence (large cancelling coefficients) visible. |
| `A3_radial_wavefunctions` | Reconstructed S-wave amplitudes `u(r)` for 1S/2S/3S per sector, showing 0/1/2 radial nodes and the tighter binding of heavier systems. |
| `A4_gaussian_mesh` | The geometric width mesh `ν_n=1/r_n²` and the length scales `r_n` it spans (n_max=25, r∈[0.05,15] GeV⁻¹). |

## B — Mass spectra & Hamiltonian-vs-literature comparison
| File | What it shows |
|------|----------------|
| `B_spectrum_cc` / `B_spectrum_bb` / `B_spectrum_bc` | Grotrian-style level diagrams: calculated masses (with **model-uncertainty error bars**) vs PDG 2024, grouped by L. |
| `B_literature_cc` | Charmonium `M_model − M_exp` [MeV], per state, for **this work** (with computation error bars) vs **six** literature models (see below). Green band = ±10 MeV theory systematic. |
| `B_literature_bb` | Bottomonium, this work vs **five** literature models. |
| `B_model_rms` | Aggregate accuracy: RMS(`M_model − M_exp`) per model over a common set of experimentally-known states (cc and bb). This work is **hatched** because it is *fitted* to these masses, whereas the literature values are genuine predictions — so this work sitting low is expected, and the bar heights of the other models are the meaningful comparison. |

## C — Fit-quality diagnostics
| File | What it shows |
|------|----------------|
| `C1_mass_residuals` | `M_calc − M_exp` per state (bb, cc) with model-uncertainty bars and the ±10 MeV systematic band. |
| `C2_pulls` | Pulls `(M_calc−M_exp)/σ_phys` with ±1σ, ±2σ guides. |
| `C3_chi2_rms_crossval` | Reduced χ²/dof, model-independent RMS deviation, and leave-one-out cross-validation (train vs test RMS) per sector. |

## E — Physics inputs
| File | What it shows |
|------|----------------|
| `E1_cornell_potentials` | The four fitted Cornell potentials `V(r)=−(4/3)α_s/r+br+c`. |
| `E2_running_coupling` | Effective `α_s` vs reduced-mass scale: cc and bb anchor the RG log-interpolation used to fix the B_c coupling; D is shown frozen/off-curve. Right panel: string tension `b` and offset `c` per sector. |
| `E3_cornell_literature` | **Cornell potential vs. literature.** Left: the Cornell shape `V̂(r)=−(4/3)α_s/r+br` (constant `c` dropped) for this work's sectors overlaid with the canonical Eichten et al. 1980 Cornell potential. ## Literature models (used in `B_literature_*` and `B_model_rms`)

Values live in `scripts/literature_data.py`. Charmonium uses six models, bottomonium five.

- **Soni 2018** — N. R. Soni et al., *QQ̄ (Q∈{b,c}) spectroscopy using the Cornell potential*, Eur. Phys. J. C **78**, 592 (2018), arXiv:1707.07144. Nonrelativistic Cornell potential (closest methodology to this work). [cc + bb]
- **EFG 2011** — D. Ebert, R. N. Faustov, V. O. Galkin, *Spectroscopy and Regge trajectories of heavy quarkonia and Bc mesons*, Eur. Phys. J. C **71**, 1825 (2011), arXiv:1111.0454. Relativistic quasipotential quark model. [cc + bb]
- **Deng 2017** — W.-J. Deng, H. Liu, L.-C. Gui, X.-H. Zhong, Phys. Rev. D **95**, 034026 (cc) / 074002 (bb) (2017). Relativized GI model with a screened linear potential. [cc + bb]
- **Radford–Repko** — S. F. Radford, W. W. Repko, Phys. Rev. D **75**, 074031 (2007, cc) / Nucl. Phys. A **865**, 69 (2011, bb). Cornell potential with full one-loop QCD radiative corrections. [cc + bb]
- **BGS 2005** — T. Barnes, S. Godfrey, E. S. Swanson, *Higher Charmonia*, Phys. Rev. D **72**, 054026 (2005), arXiv:hep-ph/0505002. NR and GI columns. [cc]
- **Godfrey–Moats 2015** — S. Godfrey, K. Moats, *Bottomonium Mesons and Strategies for Their Observation*, Phys. Rev. D **92**, 054034 (2015), arXiv:1507.00024, GI column. [bb]

BGS and Godfrey–Moats were read from their own primary papers; the Soni/EFG/Deng/Radford–Repko values were taken from the state-aligned comparison Tables II–V of Soni 2018, which collect them against a common state assignment.
